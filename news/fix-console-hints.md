* Every hint a job gives about running, following or stopping it now names the R console call (`run_job()`, `job_status()`, `cancel_job()`) instead of the `hvti` shell command: the preflight fixes `run_job()` prints, the progress lines it prints while waiting, the failure diagnosis `job_status()` shows, and the "Run it" section of each template's run sheet. The templates README leads with the console calls and keeps `hvti` as the route for a session started on the wrong R.
