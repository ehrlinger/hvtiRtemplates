- A figure is now drawn into a scratch file and moved into place only once drawing finishes. A draw that fails leaves the earlier render's figure in place. A page that draws nothing leaves no earlier PNG behind, so the `ar` report never takes a stale PNG as the current figure, and without ragg an earlier TIFF is removed rather than left beside the new PNG and PDF. An earlier figure that cannot be removed, such as one held open on the share, stops the render with its path.
