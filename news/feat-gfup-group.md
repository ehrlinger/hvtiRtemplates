* `dc-gfup` takes an optional `GROUP`, a column such as an era, a procedure or a treatment arm. When it is set, the report adds a table summarizing each follow-up interval within each group, with the statistics of the main follow-up table. Patients with no value for the column form a `"(missing)"` group, so the groups add up to the cohort, and a column that identifies patients is refused. Asked for at the 2026-11-11 Biostats training.
