- A figure that draws nothing is now recognised on Windows, where the PNG device writes a blank image for an empty page: whether anything was drawn is read from the base and grid new-page hooks and grid's display list rather than from the file, so the blank figure is not recorded as an exhibit and its earlier PDF and TIFF are removed on every platform. A drawing that closes its own device keeps its figure. A figure that is a link is followed on Windows too, where `Sys.readlink()` is not implemented, and a link there whose target is missing is refused rather than replaced. A study reached through a linked folder keeps its own path in error messages.
