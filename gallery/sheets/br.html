br: Bootstrap regression

Run sheet

What it does

Bootstrap variable-selection screen over a linear model. See the report it produces on the gallery's synthetic study.

Prerequisites

  • A study. The job runs inside a study folder set up with _study.yml. Start a new study shows how.
  • The study's data. Its choices name the registered dataset it reads. A draft can read a build that is not registered yet, so you can start before the build is final, and the report then says it is a draft. A final render reads registered data only: register the build with hvtiRutilities::update_manifest() first.
  • Its bootstrap runner, run first. The screen runs in a companion script, br.<subject>.<type>.runner.R, which add_job() writes beside the job. This job reports on what the runner saved.
  • Packages: hvtiRbootstrap (>= 0.9.3), hvtiRutilities, ggplot2. The job checks each floor when it starts, so an older library stops it at the top rather than partway through.

Run it

Render a draft as you go. render_job(job) runs the whole job in a clean R session and writes the report beside it. Render early and often: while any EDIT: marker is left, the report opens with a DRAFT banner listing them, and its numbers are not a result. Work a job explains why to render rather than run chunks by hand.

Then the final. Once no marker is left, render_job(job, final = TRUE) renders the accepted result. It refuses an open marker, a skipped chunk, stop_here() and unregistered data, and it records the job's provenance beside the report.
