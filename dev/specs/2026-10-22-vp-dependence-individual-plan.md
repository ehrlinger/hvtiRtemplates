# `vp-dependence` and `vp-individual` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `vp-dependence.qmd` (unsupervised VarPro dependence graph with a permuted-noise edge bar and stability over subsamples) and `vp-individual.qmd` (case-level VarPro gradients read from `vp-fit`'s `vp.rds`), both at ledger status `in-flight`.

**Architecture:** Two self-contained Quarto templates in `inst/templates/30_analyses/`. `vp-dependence` reads the dataset, fits `varPro::uvarpro()`, builds the importance matrix with `get.beta.entropy(pre.filter = FALSE)`, and saves `dependence.rds`. `vp-individual` reads `vp.rds` the way `vp-explain` does, runs `varPro::ivarpro()` and saves `individual.rds`. Pure decision logic (`vpd_parent()`, `vpd_square()`, `vpd_bar()`, `vpi_coverage()`) sits in chunks of its own so tests run it on hand-built inputs with no fit. The `vp` prefix and taxonomy row already exist, so everything lands in this repo in one branch.

**Tech Stack:** R, Quarto, varPro 3.3.0 (`uvarpro`, `get.beta.entropy`, `ivarpro`), ggRandomForests 4.0.0 (`gg_udependent`), ggraph 2.2.2, ggplot2, hvtiRutilities (`cache_fit()`), testthat edition 3.

**Spec:** [`2026-10-22-vp-dependence-individual-design.md`](2026-10-22-vp-dependence-individual-design.md). Read its section 8 (the spike) before Task 2.

```r
# The decisions this job makes from the importance matrix, in one chunk of
# their own so they can be checked on a hand-built matrix without a fit.
#
# varPro splits a factor into one 0/1 column per level, so the matrix names
# processed terms ("g1u"), not variables ("g1"). Each term belongs to the
# longest variable name it starts with, so "fsb" belongs to "fs", not "f".
vpd_parent <- function(terms, sources) {
  sources <- sources[order(-nchar(sources))]
  stats::setNames(vapply(terms, function(t) {
    hit <- sources[startsWith(t, sources)]
    if (length(hit)) hit[[1L]] else NA_character_
  }, ""), terms)
}
# get.beta.entropy() returns rows only for the variables that formed a
# contrast, so the matrix is padded to square, missing entries 0. A patient is
# only ever one level of a factor, so links between two levels say nothing
# about the data and are zeroed, as gg_udependent() does.
vpd_square <- function(I, parent) {
  nm <- union(rownames(I), colnames(I))
  sq <- matrix(0, length(nm), length(nm), dimnames = list(nm, nm))
  sq[rownames(I), colnames(I)] <- I
  p <- parent[nm]
  same <- outer(p, p, "==")
  same[is.na(same)] <- FALSE
  sq[same] <- 0
  diag(sq) <- 0
  sq
}
# The bar: the largest weight any noise term reached, released (its row) or
# as a predictor (its column). Both are chance. A bar is usable only above 0;
# when no noise earned any weight the fixed threshold stands in, and says so.
vpd_bar <- function(I, noise, fixed) {
  w <- c(I[noise, , drop = FALSE], I[, noise, drop = FALSE])
  w <- w[is.finite(w)]
  if (length(w) && max(w) > 0) list(bar = max(w), from = "noise") else list(bar = fixed, from = "fixed (fallback)")
}
```

# A cohort with one planted dependence: c follows a. b, x2 and the two-level
# fs are null. No three-level factor: its levels would dominate the release
# rows (spec section 8). time/event are there for the MRN fixture's shape only.
vpd_data <- function(n = 200L, seed = 20261022L) {
  withr::with_seed(seed, {
    d <- data.frame(a = stats::rnorm(n), b = stats::rnorm(n), x2 = stats::rnorm(n),
                    fs = factor(sample(c("a", "b"), n, replace = TRUE)))
    d$c <- d$a + stats::rnorm(n, 0, 0.3)
  })
  d
}

                    NOISE_N = 4, NTREE = 30, REPEATS = 0, SEED = 1, SAVE_FIGURES = FALSE)

# Every chunk of vp-dependence, in order. Task 3 adds "tbl-stability".

#| label: individual-helpers
# One row per processed predictor: how many patients have no local estimate,
# the typical size of the rest, and what the screen said about its variable.
vpi_coverage <- function(grad, parent, screen) {
  terms <- names(grad)
  out <- data.frame(
    term = terms, variable = unname(parent[terms]),
    share_na = vapply(grad, function(g) mean(is.na(g)), numeric(1L)),
    median_abs = vapply(grad, function(g) if (all(is.na(g))) NA_real_ else stats::median(abs(g), na.rm = TRUE), numeric(1L)),
    row.names = NULL
  )
  m <- match(out$variable, screen$variable)
  out$noise <- screen$noise[m] %in% TRUE
  out$tested <- screen$tested[m] %in% TRUE
  out$selected <- screen$selected[m] %in% TRUE
  out$drawn <- out$share_na < 1
  out
}
# The noise reference: the 95th percentile of the noise columns' absolute
# gradients, when the rules released any noise column. With guided split
# weights they usually did not, and the report says so rather than invent one.
vpi_noise_ref <- function(cov, grad = NULL) {
  nz <- cov$term[cov$noise & cov$drawn]
  if (!length(nz) || is.null(grad)) {
    return(list(value = NA_real_, text = "no noise reference: the screen's rules never released a noise column"))
  }
  v <- stats::quantile(abs(unlist(grad[nz])), 0.95, na.rm = TRUE, names = FALSE)
  list(value = v, text = sprintf("noise reference (95th percentile of |gradient| over %d noise columns): %.3g", length(nz), v))
}
