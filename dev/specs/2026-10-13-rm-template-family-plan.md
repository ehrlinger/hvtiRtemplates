# `rm` Regression-Model Template Family Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `rm-balancing_continuous` and `rm-linear`, two thin Quarto jobs over an OLS engine in `hvtiRpropensity`, replacing the catalog's unqualified `rm` row.

**Architecture:** A content census decides which shapes ship. `hvtiRpropensity` gains `fit_linear()` and brings `bs_continuous()` onto the result contract `fit_logistic()` and `bs_count()` already return, both through the existing `.fit_imputations()` and `.model_inference()` primitives with a new `"linear"` family. `hvtiRtemplates` adds two templates modeled on `lm-balancing_count.qmd`, and replaces the catalog row.

**Tech Stack:** Python 3 (census), R (`stats::lm`, testthat 3e), Quarto, SAS 9.4 (a one-off oracle run by John; never part of any workflow).

**Spec:** `dev/specs/2026-10-13-rm-template-family-design.md`. Read it first.

## Global Constraints

- Every `rm` row is qualified; no `rm.qmd`. A prefix is wholly qualified or wholly unqualified (`check-roadmap-counts.py`).
- Census admits only `PROC REG` / `PROC GLM` (and R `lm(`) with a continuous response. `PROC MIXED`, `PROC GENMOD`, `PROC NLIN` under an `rm` name are migration findings for `mm`, `gm`, `nm`.
- Only aggregate counts enter either repository. No study names, paths, identifiers or built-dataset names. The census's private per-file CSV is written **outside** every repository.
- Resolve the share's mount with `mount | grep -i qhs`; never hard-code `/Volumes/qhsstudies` or its `-1` spelling, and never run `find` on the share.
- No pooling code in a template. Rubin pooling lives in `hvtiRpropensity` only.
- Templates call engines by full namespace: `hvtiRpropensity::fit_linear()`, never bare `fit_linear()` (`hvtiRbootstrap::fit_linear()` exists with another signature).
- Roxygen in `hvtiRtemplates` is Rd markup, not markdown. `hvtiRpropensity` roxygen uses markdown (backticks), as its existing files do.
- Versions: straight three digits, patch bumps only. A pull request adds a `news/<branch>.md` fragment and does not touch `Version:` or `NEWS.md`.
- Never push to `main`. Branch, PR, John merges. Run `/code-review` locally before each PR and say so in the PR body.
- Never `git add -A` after a test run: a failing testthat run writes `tests/testthat/_problems/`.
- `hvtiRtemplates` lines ≤ 135 characters; `hvtiRpropensity` follows its own `.lintr`.
- Definition of done in each repo: tests pass, `devtools::check()` 0/0/0, `devtools::document()` run and `man/` + `NAMESPACE` committed.

`dev/specs/artifacts/2026-10-13-rm-shape-census.py`, the sibling of `2026-09-21-lm-shape-census.py`. Same traversal, private CSV and public JSON; different signals and classes:

```python
#!/usr/bin/env python3
"""Classify legacy rm analysis jobs without publishing study identifiers.

Sibling of 2026-09-21-lm-shape-census.py; see the rm family design, section 2.
Only PROC REG / PROC GLM (or R lm()) with a continuous response is an rm shape.
MIXED, GENMOD and NLIN fits filed as rm are migration findings for mm, gm, nm.
"""

import argparse
import csv
import hashlib
import json
import os
import re
from collections import defaultdict
from datetime import date
from pathlib import Path


SHAPES = ("balancing_continuous", "linear")
MIGRATIONS = ("migration_mm", "migration_gm", "migration_nm")
PROGRAM_SUFFIXES = {".sas", ".r", ".rmd", ".rnw", ".qmd"}
PREFIX_RE = re.compile(r"(?:^|[._-])(rm)(?:[._-]|$)", re.IGNORECASE)
SKIP_DIRS = {".git", ".rproj.user", "node_modules", "packrat", "renv"}


def study_key(path):
    parts = path.parts
    lowered = [part.lower() for part in parts]
    at = next(
        i for i, part in enumerate(lowered)
        if part in {"analyses", "30_analyses"}
    )
    return str(Path(*parts[:at]))


def signals(path, text):
    lower_name = path.name.lower()
    lower = text.lower()
    both = lower_name + "\n" + lower
    return {
        "ols": bool(re.search(r"\bproc\s+(?:reg|glm)\b|(?<![._a-z])lm\s*\(", lower)),
        "mixed": bool(re.search(r"\bproc\s+(?:mixed|glimmix)\b|\blmer?\s*\(|\blme\s*\(", lower)),
        "genmod": bool(re.search(r"\bproc\s+genmod\b|\bglm\.nb\s*\(|(?<![._a-z])glm\s*\(", lower)),
        "nlin": bool(re.search(r"\bproc\s+nlin\b|\bnls\s*\(", lower)),
        "balancing": bool(re.search(
            r"balanc(?:e|ing)[ _-]*score|balncing|%grp\b|\bbs_continuous\s*\(", both
        )),
        "transformed": bool(re.search(r"\blog\s*\(|\blog10\s*\(|\bsqrt\s*\(|\bln_", lower)),
        "mi": bool(re.search(r"_imputation_|\bimputation(?:_col)?\b|\bproc\s+mianalyze\b", lower)),
    }


def classify(found):
    others = [name for name in ("mixed", "genmod", "nlin") if found[name]]
    if found["ols"] and others:
        return "manual_review"
    if found["ols"]:
        return "balancing_continuous" if found["balancing"] else "linear"
    if len(others) > 1:
        return "manual_review"
    if others:
        return {"mixed": "migration_mm", "genmod": "migration_gm", "nlin": "migration_nm"}[others[0]]
    return "misfiled"


def candidate_files(root):
    out = []
    traversal_errors = []
    for directory, subdirs, files in os.walk(
            str(root), onerror=traversal_errors.append):
        subdirs[:] = [name for name in subdirs if name.lower() not in SKIP_DIRS]
        base = Path(directory)
        folders = {part.lower() for part in base.parts}
        if not folders.intersection({"analyses", "30_analyses"}):
            continue
        for name in files:
            if PREFIX_RE.search(name) and Path(name).suffix.lower() in PROGRAM_SUFFIXES:
                out.append(base / name)
    return sorted(out), len(traversal_errors)


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("corpus_root", type=Path)
    parser.add_argument("private_csv", type=Path)
    parser.add_argument("public_json", type=Path)
    args = parser.parse_args()

    rows = []
    unreadable_candidates = 0
    candidates, traversal_errors = candidate_files(args.corpus_root)
    for path in candidates:
        try:
            raw = path.read_bytes()
        except OSError:
            unreadable_candidates += 1
            continue
        found = signals(path, raw.decode("utf-8", errors="ignore"))
        rows.append({
            "sha256": hashlib.sha256(raw).hexdigest(),
            "extension": path.suffix.lower(),
            "path": str(path),
            "study": study_key(path),
            "shape": classify(found),
            "mi": found["mi"],
            "transformed": found["transformed"],
        })
    if not rows:
        raise SystemExit("No rm candidates found: check the corpus root and the mount name.")

    args.private_csv.parent.mkdir(parents=True, exist_ok=True)
    with args.private_csv.open("w", newline="", encoding="utf-8") as handle:
        writer = csv.DictWriter(handle, fieldnames=rows[0].keys())
        writer.writeheader()
        writer.writerows(rows)

    aggregate = defaultdict(lambda: {
        "sas_programs": 0, "sas_studies": set(), "r_jobs": 0, "r_studies": set(),
        "mi_programs": 0, "transformed_programs": 0, "transformed_studies": set(),
    })
    for row in rows:
        values = aggregate[row["shape"]]
        if row["extension"] == ".sas":
            values["sas_programs"] += 1
            values["sas_studies"].add(row["study"])
            values["mi_programs"] += int(row["mi"])
            if row["transformed"]:
                values["transformed_programs"] += 1
                values["transformed_studies"].add(row["study"])
        else:
            values["r_jobs"] += 1
            values["r_studies"].add(row["study"])

    def public(shape):
        values = aggregate[shape]
        sas_studies, r_studies = len(values["sas_studies"]), len(values["r_studies"])
        return {
            "sas_programs": values["sas_programs"],
            "sas_studies": sas_studies,
            "r_jobs": values["r_jobs"],
            "r_studies": r_studies,
            "mi_programs": values["mi_programs"],
            "transformed_programs": values["transformed_programs"],
            "transformed_studies": len(values["transformed_studies"]),
            "two_study_gate": max(sas_studies, r_studies) >= 2,
        }

    sas_rows = [row for row in rows if row["extension"] == ".sas"]
    result = {
        "date": date.today().isoformat(),
        "corpus_programs": len(sas_rows),
        "sas_breadth": len({row["study"] for row in rows}),
        "sas_breadth_jobs": len({row["study"] for row in sas_rows}),
        "manual_review_programs": sum(r["shape"] == "manual_review" for r in sas_rows),
        "misfiled_programs": sum(r["shape"] == "misfiled" for r in sas_rows),
        "traversal_errors": traversal_errors,
        "unreadable_candidates": unreadable_candidates,
        "shapes": {shape: public(shape) for shape in SHAPES},
        "migrations": {shape: public(shape)["sas_programs"] for shape in MIGRATIONS},
    }
    args.public_json.parent.mkdir(parents=True, exist_ok=True)
    args.public_json.write_text(json.dumps(result, indent=2) + "\n", encoding="utf-8")


if __name__ == "__main__":
    main()
```

```r
#' Stop when a fitted linear model has an aliased term
#'
#' `stats::lm()` returns `NA` for a term it cannot estimate, which would
#' otherwise surface later as an anonymous non-finite coefficient.
#'
#' @param models Named list of fitted models.
#' @return Invisible `NULL`.
#' @keywords internal
.check_aliased <- function(models) {
  for (i in seq_along(models)) {
    aliased <- names(stats::coef(models[[i]]))[is.na(stats::coef(models[[i]]))]
    if (length(aliased)) {
      label <- if (is.null(names(models))) i else names(models)[[i]]
      rlang::abort(
        sprintf("Term(s) aliased in imputation %s: %s. Remove them from the formula.",
                label, paste(aliased, collapse = ", ")),
        call. = FALSE
      )
    }
  }
  invisible(NULL)
}


#' Fit an ordinary least-squares model bundle
#'
#' Fits `stats::lm()` to one dataset, or once per imputation of stacked
#' long-form data, and combines imputations with Rubin's rules. A single fit is
#' inferred on the t with its residual degrees of freedom, as `PROC REG`
#' reports it.
#'
#' @param formula Model formula. The response may be transformed, e.g.
#'   `log(los) ~ age`.
#' @param data A data frame, or stacked imputations when `imputation_col` is set.
#' @param outcome_col Outcome column. By default the one variable in the
#'   formula's response.
#' @param id_col Patient identifier column.
#' @param imputation_col Imputation-index column, or `NULL` for one dataset.
#' @param prediction_col Name of the fitted-value column added to `$data`,
#'   averaged across imputations.
#'
#' @return An object of class `c("rm_fit", "ps_data")`. `$tables$fit_quality`
#'   gives each fit's residual degrees of freedom, residual standard error and
#'   R-squared; R-squared is `NA` for imputed data, where Rubin's rules define
#'   none.
#'
#' @seealso [fit_logistic()], [bs_continuous()]
#'
#' @examples
#' dta <- sample_ps_data(n = 150, seed = 42)
#' fit <- fit_linear(ef ~ age + female, data = dta)
#' fit$tables$estimates[, c("term", "estimate", "std.error", "p.value")]
#' @export
fit_linear <- function(formula, data, outcome_col = NULL, id_col = "id",
                       imputation_col = NULL, prediction_col = "fitted") {
  if (!inherits(formula, "formula") || length(formula) != 3L) {
    rlang::abort("`formula` must be a two-sided R formula.", call. = FALSE)
  }
  .check_df(data)
  if (is.null(outcome_col)) {
    outcome_col <- all.vars(formula[[2L]])
    if (length(outcome_col) != 1L) {
      rlang::abort("The formula's response must name exactly one column; set `outcome_col`.",
                   call. = FALSE)
    }
  }
  .check_cols(data, outcome_col)
  if (!is.numeric(data[[outcome_col]])) {
    rlang::abort(sprintf("The outcome `%s` must be numeric for a linear model.", outcome_col),
                 call. = FALSE)
  }

  fitted <- .fit_imputations(
    data = data,
    response_col = outcome_col,
    id_col = id_col,
    imputation_col = imputation_col,
    fit_fn = function(df) stats::lm(formula, data = df, na.action = stats::na.exclude),
    predict_fn = function(fit, df) stats::predict(fit, newdata = df),
    predictor_cols = all.vars(stats::delete.response(stats::terms(formula)))
  )
  .check_aliased(fitted$models)
  inference <- .model_inference(fitted$models, "linear")
  imputed <- length(fitted$models) > 1L

  scored <- fitted$data
  scored[[prediction_col]] <- unname(fitted$predictions)
  fit_quality <- data.frame(
    imputation = names(fitted$models),
    df_residual = vapply(fitted$models, function(m) m$df.residual, numeric(1L)),
    residual_se = vapply(fitted$models, stats::sigma, numeric(1L)),
    # Rubin's rules define no pooled R-squared, so none is reported for imputed data.
    r_squared = if (imputed) NA_real_ else summary(fitted$models[[1L]])$r.squared,
    row.names = NULL,
    stringsAsFactors = FALSE
  )

  meta <- list(
    formula = formula,
    outcome_col = outcome_col,
    id_col = id_col,
    imputation_col = imputation_col,
    prediction_col = prediction_col,
    bundle_version = 1L,
    model_family = "linear",
    package_versions = c(
      R = as.character(getRversion()),
      hvtiRpropensity = as.character(utils::packageVersion("hvtiRpropensity")),
      stats = as.character(utils::packageVersion("stats"))
    ),
    method = if (imputed) "ols-MI" else "ols",
    n_imputations = length(fitted$imputations),
    n_total = nrow(scored)
  )
  tables <- list(
    estimates = inference$estimates,
    covariance = inference$covariance,
    by_imputation = inference$by_imputation,
    fit_status = fitted$status,
    fit_quality = fit_quality
  )
  new_ps_data(scored, meta, tables, fitted$models, subclass = "rm_fit")
}
```

```sas
/* rm SAS oracle: PROC REG on one dataset, and per imputation pooled by PROC MIANALYZE.
   Set only ROOT. Input is input/input.csv; output goes to out/. */
%let root=SET_ME;

proc import datafile="&root/input/input.csv" out=work.input dbms=csv replace;
  guessingrows=max;
run;

proc sort data=work.input; by _Imputation_ id; run;

/* One dataset: imputation 1 only. */
ods output ParameterEstimates=work.single_est CovB=work.single_cov;
proc reg data=work.input(where=(_Imputation_=1));
  model y = age female / covb;
  output out=work.single_scores p=fitted;
run; quit;

/* Per imputation, then Rubin's rules. */
proc reg data=work.input outest=work.mi_outest covout noprint;
  by _Imputation_;
  model y = age female;
  output out=work.mi_pred p=fitted;
run; quit;

ods output ParameterEstimates=work.pooled_est TCov=work.pooled_cov;
proc mianalyze data=work.mi_outest tcov;
  modeleffects Intercept age female;
run;

/* The balancing score is the per-patient fitted value averaged over imputations. */
proc summary data=work.mi_pred nway;
  class id;
  var fitted;
  output out=work.mi_scores(drop=_type_ _freq_) mean=fitted;
run;

data work.sas_environment;
  length product $40 version $40 platform $40 run_at $25;
```

```r
# rm: the regression-model templates. lm_chunk() and lm_eval_job() in helper-lm.R
# are generic over a template's source, so they are reused here.

rm_data <- function(n = 120L) {
  withr::local_seed(42)
  d <- data.frame(ccfid = seq_len(n), id = seq_len(n), age = stats::rnorm(n, 60, 10),
                  female = rep(0:1, length.out = n))
  d$outcome <- 20 + 0.3 * d$age - 2 * d$female + stats::rnorm(n, 0, 4)
  d$exposure <- 35 - 0.1 * d$age + 1.5 * d$female + stats::rnorm(n, 0, 3)
  d
}

rm_mi_data <- function(n = 120L) {
  d <- rm_data(n)
  second <- d
  withr::with_seed(7, second$age <- second$age + stats::rnorm(n, 0, 1))
  rbind(transform(d, imp = 1L), transform(second, imp = 2L))
}

rm_run <- function(qualifier, labels, env, choices = list()) {
  src <- readLines(template_path("rm", qualifier), warn = FALSE)
  for (label in unique(vapply(labels, setup_label, ""))) {  # nolint: object_usage_linter.
    if (identical(label, "setup")) {
      eval_setup_chunk(lm_chunk(src, label), env)  # nolint: object_usage_linter.
    } else {
      suppressMessages(eval(parse(text = lm_chunk(src, label)), envir = env))
    }
    if (identical(label, "edit-study-choices")) {
      list2env(choices, envir = env)
      if (!"tbl-data" %in% labels) {
        if (!exists(".id", envir = env, inherits = FALSE)) env$.id <- env$ID
        if (!exists("job_data", envir = env, inherits = FALSE)) env$job_data <- list()
      }
    }
  }
  invisible(env)
}

# Scaffold the `qualifier` job in a fresh study, work its EDIT: markers, and render it,
# or with `render = FALSE` evaluate its chunks in this session (lm_eval_job).
rm_render_fixture <- function(qualifier, data = NULL, render = TRUE, .local_envir = parent.frame()) {
  root <- tempfile("rm-study-")
  withr::defer(unlink(root, recursive = TRUE), envir = .local_envir)
  d <- if (is.null(data)) rm_data() else data
  suppressMessages(hvtiRutilities::study_setup(root, study = "Synthetic rm study", study_tracker_id = 42L))
  utils::write.csv(d, file.path(root, "00_datasets", "built.csv"), row.names = FALSE)
  suppressMessages(hvtiRutilities::register_data(
    root, built = "built.csv", role = "study", population = "Synthetic cohort"
  ))
  subject <- if (identical(qualifier, "balancing_continuous")) "exposure" else "outcome"
  job <- add_job("rm", subject, "analysis", dir = root, qualifier = qualifier)
  lines <- gsub("EDIT:", "REVIEWED:", readLines(job, warn = FALSE), fixed = TRUE)
  response <- if (identical(qualifier, "balancing_continuous")) "exposure" else "outcome"
  lines[grepl("^OUTCOME <- ", lines)] <- sprintf('OUTCOME <- "%s"', response)
  writeLines(lines, job)
  if (!render) return(list(root = root, job = job, env = lm_eval_job(job)))  # nolint: object_usage_linter.
  quarto::quarto_render(job, execute_dir = dirname(job), quiet = TRUE)
  list(root = root, job = job, output = sub("[.]qmd$", ".html", job))
}
```

````markdown
Fits an ordinary least-squares balancing score for a continuous exposure, such
as a nadir hematocrit or a dose: the exposure each patient was expected to
receive given their pre-exposure covariates. Patients are then stratified on
that expected value, so a within-stratum comparison sets patients with a
similar expected exposure side by side. This is a score for the exposure, not
an analysis of an outcome; `rm-linear` fits an outcome.

# EDIT: what makes a row unique; one row per patient unless repeated measures

KEY <- ID

# Optional, and needs no edit: NULL reads the cohort alone. To join one
# registered ancillary dataset (echoes, labs), name it in JOIN. The cohort
# above decides the patients, one row each; the joined records of other
# patients are dropped and counted in the data table.
#   JOIN_VARS: the cohort columns each joined row carries; NULL carries all,
#     and a column both datasets have stops, so list only those the job needs.
#   REDUCE: NULL keeps a row per joined record, keyed on that dataset's key;
#     list(rule = "first", by = "echo_date") keeps one row per patient ("last",
#     or "nearest" with to = a cohort date column). WHERE on a joined column
#     filters the records first, so "last" with WHERE echo_type == "TTE"
#     keeps each patient's last TTE. A tie stops: picking one record
#     silently would be a hidden choice; by = c("echo_date", "echo_seq")
#     breaks it. This job models one row per
#     patient, so a JOIN without REDUCE stops here.
#   JOIN_KEY: overrides the joined dataset's registered key.
JOIN <- NULL
JOIN_VARS <- NULL
REDUCE <- NULL
JOIN_KEY <- NULL
````
