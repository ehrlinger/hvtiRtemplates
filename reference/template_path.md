# Path to a supported template

Path to a supported template

## Usage

``` r
template_path(name)
```

## Arguments

- name:

  Template name, e.g. \`"hz"\`. See \[template_list()\].

## Value

The full path, as \`character(1)\`.

## Examples

``` r
try(template_path("hz"))
#> Error : unknown template: hz. Available: ac
```
